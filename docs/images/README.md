# Documentation images

The figures shown in the project README and on the documentation site. Each
section says what draws it; redraw a figure there, never by hand.

## Alignment preview

`alignment-demo.png` is saved by the index-shift section of
[`03_faults_repairs_and_replay.ipynb`](../../tutorials/03_faults_repairs_and_replay.ipynb)
(cell `05-alignment-plot`): a seasonal forecast with its dates shifted by one
step, against the dates asked for. It is shown in the project README. Run that notebook to
refresh it.

## Custom-model preview

`custom-model-knn.png` is generated by
[`02_custom_model.ipynb`](../../tutorials/02_custom_model.ipynb). Run that notebook to refresh
the three-scenario, two-seed nearest-analogue comparison. It uses the retained
forecast plots with known future means and explicit contract status.

## Scorecard preview

`scorecard.png` and `scorecard-compact.png` are the full and compact scorecards
of the last-value forecaster, drawn by
[`examples/scorecard.py`](../../examples/scorecard.py):

```bash
python examples/scorecard.py docs/images/scorecard.png
python -c "from timegym import NaiveForecaster, Pipeline; Pipeline(NaiveForecaster()).scorecard().save('docs/images/scorecard-compact.png', compact=True)"
```

[13 · Scorecard](../../source/13_scorecard.ipynb) explains how they are built.

## README figures

`readme-trend-scorecard.png`, `readme-trend-forecasts.png`,
`readme-trend-errors.png` and `readme-custom-scenarios.png` show the output of
the README's "More things to do with a scorecard". Redraw all four after a
plotting change with
[`tools/readme_figures.py`](../../tools/readme_figures.py):

```bash
python tools/readme_figures.py
```
