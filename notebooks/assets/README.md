# Notebook preview

`quick-start-matrix.png`, at the top of the project README, is the forecast
matrix from the earlier quick start: six kinds of series by three seeds, forecast
by the recursive Ridge pipeline. The quick start now opens with the scorecard
instead. The same settings live in
[`paper/figure_matrix.py`](../../paper/figure_matrix.py), which draws the
paper's version of this figure.

`alignment-demo.png` is saved by the index-shift section of
[`23_faults_repairs_and_replay.ipynb`](../23_faults_repairs_and_replay.ipynb)
(cell `05-alignment-plot`): a seasonal forecast with its dates shifted by one
step, against the dates asked for. It is shown in the project README. Run that notebook to
refresh it.

## Custom-model preview

`custom-model-knn.png` is generated by
[`28_custom_model.ipynb`](../28_custom_model.ipynb). Run that notebook to refresh
the three-scenario, two-seed nearest-analogue comparison. It uses the retained
forecast plots with known future means and explicit contract status.

## Scorecard preview

`scorecard.png` and `scorecard-compact.png` are the full and compact scorecards
of the last-value forecaster, drawn by
[`examples/scorecard.py`](../../examples/scorecard.py):

```bash
python examples/scorecard.py notebooks/assets/scorecard.png
python -c "from timegym import NaiveForecaster, Pipeline; Pipeline(NaiveForecaster()).scorecard().save('notebooks/assets/scorecard-compact.png', compact=True)"
```

[13 · Scorecard](../13_scorecard.ipynb) explains how they are built.
