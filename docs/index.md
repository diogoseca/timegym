# TimeGym v2

TimeGym is a small verification layer for forecasting systems. Start with the
[visual Quick Start](../notebooks/00_quick_start.ipynb) or
[Python quick start](../examples/quickstart.py), then consult the
[API contracts](reference.md) and [migration notes](migration.md).

The [unified notebook guide](../notebooks/README.md) covers both developing the
package and using it. Thirteen source notebooks generate the library; seven
application notebooks explore forecasts, marginal and joint uncertainty, faults,
repairs, real data, and capability sweeps. See [working with notebooks](notebooks.md)
for setup and execution, and [contributing](contributing.md) for the edit/export/test
cycle. The [original notebooks](../notebooks/archive/README.md) preserve the
2021 development history.

The [controlled study](../experiments/README.md) evaluates selected injected
faults and repairs. The [new manuscript](../paper/main.tex) contains the methods,
measured results and limits of the evidence.
